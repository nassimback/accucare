# AccuCare

React and Vite client design showcase.

- Default homepage / design selector: `/`
- Design 2: `/design-2/`
- Design 4: `/design-4/`
- Revised Design 2: `/design-2-revised/`
- Revised Design 4: `/design-4-revised/`
- Design selector: `/designs.html`

Homepage links are placeholders for visual review. The three colour palette options remain interactive.

## Local development

Run `npm ci`, then `npm run dev`.

## Deployment

Push to `main` to build and deploy to GitHub Pages through `.github/workflows/pages.yml`.
The deployment uses `VITE_BASE_PATH=/accucare/`; local development uses `/`.

Images are stored locally; sources for replacement client images are recorded in `public/images/client/sources.json`.

## Revised concepts

The original Design 2 and Design 4 components are preserved. Revised clones reorganise the homepage around the client brief: priority services, AccuCare+ concierge, integrated nutrition and clinical coordination, the care journey, UK coverage and a Nigeria signpost, family reassurance and consultation.

The brief confirms three concierge tiers but does not specify their names, prices or inclusions. The showcase explains the tiered offering without inventing package details. Unverified experience statistics are omitted from the revised pages. All homepage links remain placeholders and revised sample forms do not transmit enquiries.
